# Customer Call List Data Cleaning & Processing

A Python-based data cleaning project focused on processing and refining an unorganized raw customer call list into a clean, structured dataset ready for analysis or CRM integration.

---

##  Project Overview
Raw customer data often contains missing values, duplicate entries, inconsistent formatting (e.g., phone numbers, addresses), and unnecessary special characters. 

This project demonstrates an end-to-end data cleaning workflow applied to a simulated customer dataset (`Customer Call List`).

---

##  Key Cleaning Operations
- **Duplicates Removal:** Detected and dropped duplicate records.
- **Phone Number Standardizing:** Removed non-numeric characters and unified number formatting.
- **Address Splitting:** Separated raw address lines into standard components (Street Address, State, Zip Code).
- **Missing & Blank Value Handling:** Handled `NaN`, `N/A`, and empty fields across key contact columns.


---

##  Tools & Libraries
- **Python 3.x**
- **Pandas** (Data manipulation and transformation)
